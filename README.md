# 🐍 Meus Primeiros Projetos em Python

Este repositório reúne as minhas primeiras resoluções práticas de desafios propostos no curso de Python do **Canal Curso em Vídeo (Prof. Gustavo Guanabara)**. O objetivo deste projeto foi consolidar os pilares e fundamentos iniciais da linguagem de programação.

Para deixar a experiência mais organizada, juntei os três scripts iniciais em um único sistema de menu interativo executado via terminal.

## 🚀 Desafios Inclusos e Conceitos Aplicados

### 1️⃣ Mensagem de Boas-Vindas (`Desafio 01`)
* **O que faz:** Solicita o nome do usuário e exibe uma saudação personalizada na tela.
* **Conceitos:** Entrada de dados com `input()`, armazenamento em variáveis e exibição com f-strings (interpolação de strings).

### 2️⃣ Validador de Data de Nascimento (`Desafio 02`)
* **O que faz:** Coleta o dia, o mês e o ano de nascimento do usuário de forma individualizada e formata em uma frase estruturada para validação.
* **Conceitos:** Captura de múltiplos dados textuais e concatenação limpa e espaçada.

### 3️⃣ Mini Calculadora de Junção (`Desafio 03`)
* **O que faz:** Recebe dois números informados pelo usuário e exibe o resultado da junção textual deles.
* **Conceitos:** Entendimento do comportamento padrão do `input()` (que captura dados nativamente como tipo String/Texto) e aplicação prática de concatenação de strings usando o operador `+`.

## 🛠️ Como executar os scripts localmente
1. Certifique-se de ter o Python instalado em seu computador.
2. Abra o terminal ou prompt de comando (CMD) na pasta do projeto.
3. Digite e execute o comando:
```bash
python main.py
```
